# 音频流协议规范 (AirMic Protocol Specification)

## 1. 架构概览
AirMic 参考 WO Mic 架构，分为手机端发送端（Client/Transmitter）与电脑端接收端（Server/Virtual Microphone Driver/Receiver）。

```
+--------------------------+                         +-----------------------------------+
|       手机端 (Client)     |                         |           电脑端 (Server)          |
| 1. 麦克风录音 (PCM/Opus)  |                         | 1. 接收流 (UDP / WebSocket / TCP) |
| 2. 状态机与重连控制       | ----(Wi-Fi / USB)---->  | 2. Jitter Buffer & 平滑滤波       |
| 3. 参数调节 (采样率/增益) |                         | 3. 音频路由 (虚拟麦克风 / 监听)   |
| 4. 扫码一键连接           |                         | 4. UI 仪表盘 (电平/延迟/状态监控) |
+--------------------------+                         +-----------------------------------+
                                                                     |
                                                                     v
                                                   +-----------------------------------+
                                                   | 系统级虚拟麦克风 (Virtual Mic)    |
                                                   | 第三方软件 (微信/腾讯会议/OBS/录音)|
                                                   +-----------------------------------+
```

## 2. 传输模式
1. **Wi-Fi / 局域网模式**：
   - 控制信令：WebSocket / HTTP REST，端口 `8090`，传输采样率协商、启停指令、Ping/Pong 心跳测量网络 RTT
   - 音频数据：
     - 高吞吐 / 浏览器零安装：二进制 WebSocket (PCM Int16 / Float32 块)
     - 极低延迟原生传输：UDP 端口 `8091`（含 12 字节序列号与时间戳头，电脑端自动丢弃乱序包、乱序重排）
2. **USB (ADB 端口转发) 模式**：
   - 通过 `adb forward tcp:8090 tcp:8090`，手机插上 USB 打开开发者调试后直接零延迟走物理线路传输，不受无线信道干扰。
3. **热点 (AP) 模式**：
   - 电脑开移动热点或手机开热点，自动获取网卡网段，无路由器环境下稳定工作。

## 3. 音频数据包结构 (UDP / 二进制帧)
```
+-------------------+-------------------+-------------------+-------------------+
| Magic (2 Bytes)   | SeqNum (2 Bytes)  | Timestamp (4 Bytes)| Payload Length(2B)|
| 0x41 0x4D ('AM')  | uint16 (0-65535)  | uint32 (毫秒)      | uint16            |
+-------------------+-------------------+-------------------+-------------------+
| Audio PCM Data (16-bit Mono, Little-Endian, 16000Hz / 44100Hz / 48000Hz)      |
+-------------------------------------------------------------------------------+
```

## 4. 虚拟麦克风 (Virtual Audio Cable) 对接方案
在 Windows 平台上，第三方软件（QQ、微信、腾讯会议、录音机、OBS）要求声卡设备呈现为标准的 Windows 录音设备（Audio Capture Endpoint）。
主流实现方案：
1. **VB-Audio Virtual Cable / Hi-Fi Cable**（业界最稳定通用标准，WO Mic 官方同款推荐方案）
   - 原理：电脑端将接收并解码后的手机音频输出到 `CABLE Input (VB-Audio Virtual Cable)`，第三方会议软件的录音麦克风直接选择 `CABLE Output (VB-Audio Virtual Cable)` 即可。
2. **内置虚拟音频驱动安装/检测引导**：
   - 电脑端自动检测系统是否已存在虚拟麦克风驱动，一键指引安装或静默下载配置。
3. **实时声卡监听**：
   - 方便用户直接通过电脑耳机测试听取手机麦克风效果，实时监看声波波形与电平米。
