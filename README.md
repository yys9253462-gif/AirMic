# AirMic - 手机麦克风转电脑系统级麦克风软件 (开源版)

> 参考并超越 WO Mic 设计，实现将手机麦克风以超低延迟（~20ms）、广播级超清音质（最高支持 192kHz）传输至 Windows 电脑端，并注册为系统级录音设备，供腾讯会议、微信、OBS、剪映、录音等各类第三方软件直接选用。

---

## 🌟 核心特性与亮点

1. **零配置自动配对 (免输入任何 IP)**
   - 手机端与 Windows 客户端同时打开，一键点击配对即可秒级自动建立双向受信任连接。
   - 内置「UDP 广播中枢 + 原生 TCP/HTTP 局域网快速穿透探测」双通道，**彻底突破家用/办公路由器拦截 UDP 广播或 AP 隔离的限制**。
   - 双端均具备高辨识度的配对状态大卡片（黄色搜索中 ➔ 绿色配对成功），配对状态一目了然。

2. **超低感知延迟 (~20ms 电竞级)**
   - 手机端采样切片优化至 256 点（极速分包，采集周期缩减至 5.3 毫秒即时送出）。
   - 电脑端采用 NAudio 高速环形缓冲区（`DesiredLatency = 20ms`，双缓冲高速轮转），声音传输几乎与唇形完全同步。

3. **芯片级降噪与声音净化 (消除背景杂音)**
   - 切换专业通讯语音通道 `VOICE_COMMUNICATION`，激活手机音频芯片底层硬件降噪模块。
   - 深度集成 Android 原生 3 大音频特效：
     - **NoiseSuppressor (噪音抑制)**：消除环境风扇声、键盘敲击声与底噪杂音。
     - **AcousticEchoCanceler (回声消除)**：避免声卡回授啸叫。
     - **AutomaticGainControl (自动增益)**：保持平稳清晰的音量，远离爆音。

4. **全档位专业音频采样率（最高支持 192,000 Hz）**
   - **192000 Hz (192kHz)**：旗舰发烧级母带高解析度采样；
   - **96000 Hz (96kHz)**：专业录音棚级清晰度；
   - **48000 Hz (48kHz)**：广播级电影/会议标准（默认推荐）；
   - **44100 Hz (44.1kHz)**：CD 音质母带标准；
   - **16000 Hz (16kHz)**：极速低带宽对话。

5. **系统级虚拟麦克风对接 (Virtual Audio Cable)**
   - 遵循业界标准的 Windows 虚拟声卡桥接方案，完美兼容 **VB-Audio Virtual Cable**。
   - 电脑端将接收流送入虚拟声卡输入端，腾讯会议、钉钉、微信、YY、OBS 中直接选择 `CABLE Output (VB-Audio Virtual Cable)` 即可将手机作为电脑主麦克风使用。
   - 电脑端内置【🔊 测试麦克风是否正常】功能，支持扬声器/耳机独立监听与动态 RMS 绿色电平表。

## 🚀 快速使用说明

### 1. 手机端
- 直接安装 `dist/AirMic-Android-v1.0.0.apk`；
- 连接与电脑相同的 Wi-Fi，选择“Wi-Fi (自动配对)”，点击【与电脑配对并开始传输】。

### 2. 电脑端
- 双击启动 `dist/AirMic-Windows-v1.0.0.exe`（单文件独立绿色版，无需安装 .NET）；
- 双方秒级跳为绿色【✅ 配对成功】；
- 点击【🔊 测试麦克风是否正常】，对着手机麦克风说话即可在电脑扬声器听到声音并观察绿色音量跳动。

```
├── windows_app/              # Windows 桌面端 (C# .NET 8/9 + WinForms + NAudio + 原生 Socket)
├── desktop/                  # WebRTC/WebSocket 备用轻量服务
├── mobile/                   # Web Audio 纯浏览器端备用采集
├── dist/                     # 编译生成的可执行安装产物 (已包含最新 EXE & APK)
└── README.md                 # 项目文档
```
