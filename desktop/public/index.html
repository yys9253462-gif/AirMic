手机配对连接

使用手机相机或微信/浏览器扫码即可直接使用

http://127.0.0.1:8090/mobile
蓝牙连接操作要点：
1. 确保手机与电脑已在 Windows「设置 -> 蓝牙」中配对。
2. 手机端 AirMic App 勾选【蓝牙 (SPP)】并点击【开始】。
3. 在上方选择你的手机并点击【一键蓝牙配对连接】。
USB 极速物理连接模式：
1. 手机开启 USB 开发者调试
2. 执行命令：adb forward tcp:8090 tcp:8090
3. 手机浏览器直接打开 http://127.0.0.1:8090/mobile 即可享受 0 丢包与无惧无线电干扰的极致低延迟体验。

系统级虚拟麦克风对接 (供 QQ / 微信 / 会议 / 录音使用)

  1. 在 Windows 上，第三方语音通话软件需要识别系统原生录音设备。
  2. 建议安装业界开源免费的虚拟声卡驱动：VB-Audio Virtual Cable（WO Mic 同款标准）。
  3. 安装后，将本软件声音输出到 CABLE Input，在腾讯会议/微信/OBS 等软件中的麦克风直接选择 CABLE Output 即可！
  4. 点击此处 获取 VB-Audio Virtual Cable 官方免费下载。
